# Genealogy content

The reviewed-public content contract for **Where the Record Ends**. This package
contains only editorially reviewed material that may be shipped to a public
client. It deliberately has no import, build, or runtime relationship with the
private research repository.

The top-level module exports canonical people, relationships, references,
research cases, stories, media, editorial media placements, image acquisition
needs, and runtime integrity checks.

Run `npm test` in this directory to build the package and verify identifiers,
cross-references, publication fields, and media provenance.
