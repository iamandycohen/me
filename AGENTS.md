# Personal website project instructions

This repository is the `personal-website` project. Actual code, configuration,
runtime behavior, and the user's current instructions outrank dated notes.
Preserve existing local changes. For substantial work, read the workspace
bootstrap and the relevant project notes in the independent `kb` repository
when available. The website repository owns its public content and rendering.

## Genealogy publication work

Before editing `packages/genealogy-content` or `apps/where-the-record-ends`,
refresh and read `geneaology/Meason/research/coordination/public-site-handoff.md`
from the Geneaology repository's current `main`, along with
`kb/projects/personal-website/overview.md` and the accepted genealogy
publication-boundary decision. If those repositories are available only through
GitHub, use their current default branches. If the handoff is unavailable,
state that limitation instead of inferring new private findings.

Read **all pending conclusions** in the handoff, including items added since
the last website release. Review their evidence limits, privacy, and reuse
rights together. Editorially choose how supported conclusions affect public
references, people, relationships, cases, stories, maps, media, and rendered
text. One website change may address several items while others remain pending
or deferred. A pending item starts editorial review; it does not by itself
authorize public release. Do not copy private evidence files or treat an
unreviewed Computer Use report as a publication handoff.

The public references list describes sources and their limits; a reference
does not automatically establish a structured fact or tree edge. The current
tree and stories are curated. A deterministic live tree or direct database/API
projection would require a separate design decision.

After a website content pass, run the relevant content validation and report
the website branch, commit, validation, affected public routes or content
surfaces, and the disposition of **each** pending handoff item. Geneaology's
integration owner verifies those outcomes and updates the handoff in its own
repository. Do not edit the private research repository from a website session.
